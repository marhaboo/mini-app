# Mini App — Apartment Listings

A modern apartment listing application built with Next.js, TypeScript, and Tailwind CSS.

## Getting Started

### Prerequisites

- Node.js 20+
- npm 10+

### Install dependencies

```bash
npm install
```

### Run JSON Server (mock API)

```bash
npm run server
```

Runs on http://localhost:3001/apartments

### Run Next.js

```bash
npm run dev
```

Runs on http://localhost:3000


## Features

- 🏠 Apartment listing with cards
- 🔍 Search by title
- 🔧 Filter by rooms and price range
- 📄 Detail page for each apartment
- 🌙 Dark / Light mode
- 💀 Skeleton loading
- 📱 Responsive design
